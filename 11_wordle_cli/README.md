## WORDLE



What is Wordle?

Wordle is a popular daily web-based word game where players have six attempts to guess a hidden five-letter word. Using color-coded tiles (green, yellow, gray), it provides feedback on letter accuracy and placement, and is owned by The New York Times. It went viral for its simple, shareable, once-a-day format.

---

Tweaks made in this program:
* Attempts same as original game, that is 6
* The words are not five-letters only, some extend to 10 or beyond
* It is not colour coded with tiles, but feedback is returned as R(for Red), Y(for Yellow) and G(for Green)

---

This program uses the concepts of:
* Lists
* Dictionaries
* Loops
* Conditional Statements
* String manipulation
* Random Choices

---

Steps to run:

* In terminal, go to your specific folder where the file is stored
* Run - "python wordle.py"
* Choose your preferred category
* Hint shows the no. of letters the secret words have
* Try out your guessing power!
* Extra feature - You can modify the code to suit your needs!!
